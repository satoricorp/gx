Totality records which agent session produced each Git commit and uses that context
for AI code review and generated pull request summaries. You work in plain Git.

## Install

```bash
curl -fsSL https://download.totality.sh/install.sh | sh
tx auth login
```

This installs bash/zsh completions and aliases, like `txr`, for `tx review`.

## Basic Usage

```bash
cd your-repo
tx init                                # once per repo: installs the Git hooks
git add src/retry.js
git commit -m "add retry helper"       # hook records the revision
tx review                              # AI review before you push (optional)
git push                               # hook captures the session and publishes
gh pr create                           # Totality Cloud adds the summary to the PR
```

## Uninstall

```bash
rm -f ~/.local/bin/tx ~/.local/bin/txr ~/.local/bin/tx-mcp
rm -f ~/.local/share/bash-completion/completions/tx ~/.zfunc/_tx
```

Installed Git hooks exit silently when the binary is absent, so plain Git keeps
working. Local data remains in `~/.totality`.
