## New features

<Update label="Confidence-gated generate pipeline" tags={["generate"]}>
  `gx generate` now runs a new demux routing pipeline that gates changes by
  confidence before proposing revisions and stacks. Low-confidence changes are
  held back so the stack you see is the one worth pushing.

  Prefer the previous behavior? Pass `--legacy` to `gx generate` to fall back to
  the older pipeline.
</Update>

<Update label="GitHub PR summaries on push" tags={["push", "github"]}>
  When `gx push` publishes a stack to GitHub, GX writes a generated review
  summary into the pull request body — with a blast-radius overview, a
  **Needs Review** list of high-impact targets, and preserved author notes
  beneath an `## Author Notes` heading.

  See [GitHub PR summaries generated by `gx push`](/reference/github-pr-summaries)
  for the full behavior.
</Update>

<Update label="Prompted code review with policy and history" tags={["gx review"]}>
  `gx review` now accepts prompted invocations and pulls in more context on
  every run:

  - Review policy is attached to each review, so guidance you write once shapes
    every future review.
  - Indexed context from past reviews is included, and GX can post comments
    directly on the GitHub PR.
  - A per-repo code review history memory improves attribution and reporting
    over time.

  Install the `gxr` shortcut for one-keystroke reviews from your shell.
</Update>

<Update label="`gx report` and stack scrolling" tags={["cli", "tui"]}>
  A new `gx report` command surfaces stack health at a glance, and the stack
  TUIs now include a scroll viewport so long stacks are navigable end-to-end.
</Update>

<Update label="Local inference API keys" tags={["inference"]}>
  Run `gx set key` to store an Anthropic or OpenAI API key for local inference
  and MCP-launched `gx` commands. The stored key wins over the
  `ANTHROPIC_API_KEY` / `OPENAI_API_KEY` environment fallbacks.

  See the [Local inference](/#local-inference) section on the landing page.
</Update>

## Updates

<Update label="Cleaner menu-bar and status UI" tags={["menubar"]}>
  - The menu bar now shows both the app tag and the bundled CLI version.
  - Menu items and the status UI were simplified; `Shift-D` delete was removed
    to prevent accidental revision loss.
  - The Convex site no longer appears in the auth status list.
</Update>

<Update label="Smarter stack pruning" tags={["stacks"]}>
  Merged and closed GitHub PR stacks are now pruned or hidden automatically,
  empty stored stack revisions are hidden, and the stack read model is faster
  overall.
</Update>

<Update label="Login and auth reliability" tags={["auth"]}>
  - `gx` verifies your console API session on login.
  - Expiring GitHub auth tokens are refreshed automatically.
  - `gx doctor` output has been simplified, and MCP auth login guidance is
    surfaced when credentials are missing.
</Update>

<Update label="Polished CLI surface" tags={["cli"]}>
  The `gx` help surface has been tightened, and PostHog product analytics now
  ship in every event with identity attached so telemetry-driven improvements
  land faster.
</Update>

<Update label="Menu-bar app release workflow" tags={["menubar"]}>
  The macOS menu-bar app now ships with a proper release and appcast pipeline,
  so future updates arrive through the app itself.
</Update>

## Bug fixes

<Update label="Reliability" tags={["fixes"]}>
  - Fixed PostHog configuration for macOS releases and allowed main GX builds
    to run without a PostHog key.
  - Restored the `gx doctor` repo registry lookup.
  - Fixed GX branch naming and `gx compose` reliability.
  - Fixed cross-platform CLI packaging so installs work consistently.
  - Removed the MCP sync capture option that could double-capture sessions.
</Update>
